# Productivity

Daily non-code workflow tools.

| Skill | Description |
|-------|-------------|
| [`concur-expense`](concur-expense/SKILL.md) | Turn a folder of receipts into a SAP Concur expense claim — read receipts, build the report, attach images, allocate to a fund. Draft-only unless you opt in to submit. |
| [`moodle`](moodle/SKILL.md) | Administer a Moodle course from Claude Code — duplicate weekly activities, configure quizzes and Safe Exam Browser, enter gradebook marks from a spreadsheet, manage groups. Every change made in your own browser and re-read from Moodle to verify it. |
| [`overleaf`](overleaf/SKILL.md) | Work on an Overleaf project from Claude Code — read the source, apply edits as tracked-change suggestions in your own browser, compile, and keep a Dropbox mirror safely in sync. Suggestions by default, direct edits only if you ask. |
